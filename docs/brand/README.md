# คลังวัสดุ DBT — Brand guide

หน้าตัวอย่างแบบเต็ม: https://claude.ai/artifact/QFguzkRdk9feyjH7aDpbV4

ทิศทาง: ขาว-ฟ้า สะอาด อ่านสถานะได้ในแวบเดียว โลโก้เป็นจุดเดียวที่มีหลายสี

## โลโก้

- ไฟล์: `public/brand/dbt-logo.jpg` (447×447, พื้นขาว) ใช้เป็น favicon ด้วยที่ `src/app/icon.jpg`
- คอมโพเนนต์: `src/components/brand-logo.tsx` (`<BrandLogo size={36} />`)
- วางบนแผ่นวงกลมสีขาวเสมอ เว้นระยะรอบอย่างน้อย 1/4 ของความกว้าง ขนาดเล็กสุด 32px
- ห้ามยืด เปลี่ยนสี ใส่เงา หรือวางบนพื้นสีโดยไม่มีแผ่นขาว
- ถ้าได้ไฟล์ PNG/SVG พื้นโปร่งใส ให้แทนที่ไฟล์ JPG ได้ทันที

| `--brand-blue-strong` | `#08639B` | hover |

## สีสถานะคำขอยืม

ใช้ผ่าน `<LoanStatusBadge>` เท่านั้น ทุกป้ายมีจุดและคำกำกับ คลาส Tailwind: `bg-status-<name>-bg text-status-<name>`

| LoanStatus | ป้าย | ตัวอักษร / พื้น |
|---|---|---|
| PENDING | รออนุมัติ | `#8A5A0B` / `#FFF3DB` |
| APPROVED | อนุมัติแล้ว | `#08639B` / `#E3F0FC` |
| BORROWED | กำลังยืม | `#3A3FA8` / `#E9EAFB` |
| RETURNED | คืนแล้ว | `#17744C` / `#E2F5EB` |
| REJECTED | ไม่อนุมัติ | `#B3332D` / `#FCE9E8` |
| CANCELLED | ยกเลิกแล้ว | `#56657A` / `#EEF2F6` |
| เกินกำหนด | เกินกำหนด | ขาว บน `#D13A33` (สีทึบอย่างเดียวในระบบ) |

## ตัวอักษร (`src/app/layout.tsx`)

- หัวข้อ: **Anuphan** 600–700 (`font-heading`, h1–h3 อัตโนมัติ)
- เนื้อหา: **IBM Plex Sans Thai** 400–600 (`font-sans`, ค่าเริ่มต้น)
- เลขครุภัณฑ์ วันที่ จำนวน: **IBM Plex Mono** (`font-mono`)

## รูปทรง

มุมโค้ง ปุ่ม/ช่องกรอก 10px การ์ด 14px ป้าย เต็มวง แยกส่วนด้วยเส้นขอบ 1px เป็นหลัก เงาใช้กับสิ่งที่ลอยเท่านั้น ไอคอนเส้น (Lucide)

## น้ำเสียง

สั้น บอกสิ่งที่เกิดขึ้นและสิ่งที่ต้องทำต่อ ใช้คำที่ผู้ยืมเข้าใจ ("ของ", "คำขอ", "วันคืน") ไม่แสดงรหัสระบบหรือข้อความ error ภาษาอังกฤษ
